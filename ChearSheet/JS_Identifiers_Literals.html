What is an identifier?
💡A name you give to variables, functions, classes, or parameters in your code.
Rules
✓ Valid starts
letter_$

✗ Invalid starts

⚡ Case sensitive
name ≠ Name ≠ NAME
All three are different identifiers!

== vs === — the most important rule
// == loose — checks VALUE only
5  ==  "5"     // true  (ignores type)
0  ==  false  // true  (ignores type)

// === strict — checks VALUE + TYPE
5  === "5"     // false (number ≠ string)
0  === false  // false (number ≠ boolean)

null vs undefined
null
Set by you — intentionally empty
Type: "object" ⚠️ known JS bug
Example: let user = null;
undefined
Set by JavaScript automatically
Type: "undefined" ✓ correct
Example: let user;
Equality rules
null ==  undefined   // true  (loose — same "empty" value)
null === undefined   // false (strict — different types)

typeof null          // "object"    ← famous JS bug — never fixed!
typeof undefined     // "undefined" ← correct
Real world pattern
let user = null;            // before login — placeholder
user = { name: "Alice" };   // after login — assign real value

if (user === null) {
  console.log("Not logged in");
}
✅null = "I chose empty"  ·  undefined = "forgot to assign"
✅typeof null === "object" is a known JS bug — never fixed to avoid breaking old code
✅Always use === when checking for null
